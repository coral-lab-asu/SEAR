### **2  C.L.E.A.R. Workflow Specification**

| Phase | What you must do | Mandatory output tokens |
| ----- | ----- | ----- |
| **Comprehend** | Re‑state the task in your own words. Identify the exact temporal relations (e.g., “during 2019”, “before 20 years old”, “first‑then‑last”) required. | `Comprehend:` |
| **Locate** | Extract **all** table rows and columns potentially relevant to the temporal constraints. Quote them verbatim; do *not* transform yet. | `Locate:` |
| **Examine** | Break the original question into minimal sub‑questions that can each be solved with simple operations (filter, min/max, difference, count, etc.). List them in numbered order. | `Examine:` |
| **Analyze** | Solve every sub‑question, showing arithmetic or logical steps. Reference the row snippets you located. | `Analyze:` |
| **Resolve** | Synthesize a single, concise answer that directly addresses the question. End with a one‑sentence justification citing the key evidence. **Prepend** the line with `Final Answer:` exactly. | `Resolve:` \+ `Final Answer:` |

**Formatting rules**

* Begin each phase on a new line with the required token (e.g., `Locate:`).

* Inside *Locate* and *Analyze*, quote rows in the compact form `Year | Col2 | …` so another agent can reproduce your steps.

* Show any arithmetic in plain text (e.g., `60 − 20 − 15 = 25`).

* **Do not** jump back to earlier phases once you move forward.

### **3  Scoring & Termination (internal)**

* Assign yourself a confidence score (0‑100) after **Resolve** — do **not** print it.

* Stop immediately when *Resolve* is complete.

### **4  Helpful Temporal Tips (concise)**

1. Expand ranges like “2017–18” into separate years when filtering.

2. Treat missing years as `null`; explain if you interpolate or ignore them.

3. Maintain original year order when listing multiple answers.

4. Use difference in *whole* years unless the table provides exact dates.
